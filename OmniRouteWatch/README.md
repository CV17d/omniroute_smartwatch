# OmniRoute — Apple Watch Project Layout
This directory contains the watchOS client codebase for OmniRoute.

Structure:
- `App/`: watchOS App lifecycle and root view coordination
- `Models/`: Domain models and Bluetooth/WCSession DTOs
- `ViewModels/`: MVVM presentation logic and state management
- `Views/`: Full-screen glanceable watch views
- `Components/`: Atomic, reusable SwiftUI components matching reference design
- `Services/`: Bluetooth, WatchConnectivity, reachability and offline cache services
- `Utilities/`: Design system tokens (colors, typography, layout) and extensions
- `Tests/`: Unit tests and mock verification suites
